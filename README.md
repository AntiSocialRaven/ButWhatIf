# But What If X?
A Balatro mod for editing your current run and exploring what could have been.

## What it does
- **Spawner**: a grid of real cards (Jokers, Tarots, Planets, Spectrals, Vouchers, Tags). Click one to add it instantly; type to search.
- **Card editor** (right-click any joker, consumable or card in hand): change the card's own numbers (/2, -1, +1, x2, x10), bonus chips and xMult, sell value, edition, seal and enhancement; duplicate or remove it.
- Add playing cards of any rank and suit to your hand or deck
- Money, pass round and reroll boss buttons

## Hotkeys
Hotkeys are enabled by default (toggle them in the mod config). All bindings
avoid the F-key row and the Delete key, so they work on Chromebook keyboards.

Menus:
- `]` - Sandbox menu (Spawner, money, pass round, reroll boss)
- `[` - Add a playing card
- Right-click a card - Edit it
- `F2` / `F3` also open the two menus on keyboards that have an F row

Hover a card during a run, then press:
- `D` - Duplicate
- `X` or `Backspace` - Remove
- `E` / `Q` - Cycle edition forward / back
- `F` / `H` / `P` / `N` - Toggle Foil / Holo / Poly / Negative
- `S` / `A` - Cycle seal forward / back (playing cards)
- `W` / `Tab` - Cycle enhancement forward / back (playing cards)

## Installation
1. Place the `ButWhatIf` folder in your Balatro mods directory.
2. Ensure `ButWhatIf.json` and `main.lua` are present.
3. Start Balatro.

## Notes
- Requires `Steamodded (>=0.9.8)`

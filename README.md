# But What If X?
A Balatro mod for editing your current run and exploring what could have been.

## What it does
- Add cards (jokers, playing, spectral, tarot) to your current run
- Customize card edition, enhancement, and seal
- Edit Jokers/consumables and adjust chip bonuses
- Duplicate or remove cards

## Installation
1. Place the `ButWhatIf` folder in your Balatro mods directory.
2. Ensure `ButWhatIf.json` and `main.lua` are present.
3. Start Balatro.

## Notes
- Requires `Steamodded (>=0.9.8)`
